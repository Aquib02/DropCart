# DropCart - Full-Stack E-Commerce Web Application

A feature-rich, full-stack e-commerce platform built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with secure user authentication, role-based access control, persistent cart management, and real-time order tracking.

## Features

* **User Authentication & Authorization:** Secure registration and login powered by JSON Web Tokens (JWT) and bcrypt password hashing.
* **Role-Based Access Control (RBAC):** Distinct privileges for customers (shopping, cart management, ordering) and administrators (product management and dashboard controls).
* **Dynamic User Profile:** Profile management allowing users to view and update their personal details seamlessly synced with the database.
* **Shopping Cart & Checkout:** Persistent cart functionality with real-time stock validation and checkout workflow.
* **Order Tracking System:** Dedicated order history module where users can view past purchases, item-wise quantities, product images, and live statuses (Paid/COD, Processing/Delivered).
* **Admin Dashboard:** Capability for administrators to add, manage, and update products with image URLs and descriptions.

## Tech Stack

* **Frontend:** React.js, Tailwind CSS, React Router, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JWT (JSON Web Tokens), bcryptjs

## Getting Started

### Prerequisites
* Node.js and npm installed locally.
* MongoDB connection string (Local or MongoDB Atlas).
